# Low-Level-Fibonacci
Simple Project I made to see how low level I could get with the fibonacci series.

If you want to test out, clone the repo and run `make <filetype>` to compile that file (or run it in case of .py)

For the .circ file, you need logism evolution installed, and open it in there. 

.py is a Python programming language file
.c is a C programming language file
.s is x86_64 assembly language file
.hex is ELF hex coded binary file
.circ is logism evolution file

It gets more low level in the order
Python -> C -> Asm -> Hex -> Circ

The circ file is more low level as it made with raw logic gates, specifically using a 64bit RCA adder.
